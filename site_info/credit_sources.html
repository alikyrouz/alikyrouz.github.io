Inspiration (and a little bit of code for hover effects) from ribo.zone. Thank you for motivating me to improve on my personal website! I think your vibes are so cool.

All images are from Wikimedia Commons or my own. Editing is done myself in GIMP 3 and Aseprite. Unless otherwise stated, all code is handwritten.

Believe it or not, most web development skills are not formally taught as part of a Data Science degree program. This website began as one of my first projects involving HTML, CSS, JavaScript, UX/UI, and image editing/pixel art. I was super inspired by people in communities like 32bit.cafe, so I began working on this site in late spring, early summer of 2025 to replace my previous site built from a template. I like this project as a creative pursuit and a means to have a website with a little more personal identity.

As may be obvious, this entire site is hosted through GitHub Pages.
